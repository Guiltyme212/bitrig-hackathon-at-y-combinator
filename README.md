# Bitrig hackathon at Y Combinator

Kokoro for iPhone Duo. A meditation app built around the unfolding moment.

The proposed interaction: start with an orb on the outer display. Open the phone and the orb expands into a space for a guided session. Fold it back and the same session continues on the outer display.

The opening motion should have a purpose. It takes you from choosing a moment for yourself into the session, with no lost progress or interrupted playback.

This repository currently contains the project plan. App implementation and device verification are next.

See [PLAN.md](PLAN.md) for the build order and demo checks.
